# Security policy

## Supported versions

Security fixes are provided for the latest published release.

## Report a vulnerability

Do not publish exploit details in a public issue. Use GitHub's private vulnerability reporting feature for this repository. Include the affected version, reproduction steps, impact, and any proposed mitigation.

QR data is untrusted input. The app deliberately limits web actions to HTTP and HTTPS and uses typed Android intents for other content. Security reports that show a bypass of those boundaries are especially useful.
